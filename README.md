# Setup from .zip:

1. Extract the .zip file and open the terminal. Use the "cd" command to navigate to the extracted folder, or drag the folder into the terminal after typing "cd" and press the enter key.

2. Copy and paste the following command into the terminal:
"chmod +x sudo_bruteforce.command"

3. You can now run the program by double-clicking on it.

# Setup with git clone:

Here are the steps to install Git on macOS easily:

1. Open Terminal.
2. Install the Homebrew package manager by running the following command:


Copy and paste:
---------------

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

brew install git

---------------

After this, if you run the git --version command in Terminal, it should display the version of Git that you just installed. 
If you prefer not to use Homebrew, you can also download and install the Git package directly from the official website. The download link is:

https://git-scm.com/download/mac

The installation process for the downloaded package is straightforward, just follow the instructions in the installer wizard. 
However, we recommend trying to install Git using Homebrew first, as it automatically handles all dependencies and can be easily updated in the future.
